# cloud-examples

The three example projects of razo-cloud (`examples/failing-button`,
`examples/failing-table`, `examples/table-row-actions`), one run each,
captured with `scripts/capture-run.mjs`. Each has exactly one failing
test: a hidden submit button, a table with fewer rows than asserted, and
a button inside a specific table row. The sha is all zeros: the examples
have no git history of their own. Not synthetic.
